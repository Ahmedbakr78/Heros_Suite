The Suite

Every tool you reach for daily — rebuilt as one coherent family. Click through to each extension's site and repository.

Heros NoteBook

v1.1.0

Open, read, run, edit and export Jupyter .ipynb notebooks with a real Python runtime in your browser.

  • Real Python execution via Pyodide WebAssembly sandbox
  • Builder Studio, variable inspector, search and outline
  • 160 tools, full export engine, works offline
Open Studio GitHub

Heros PDF

v2.3.2

A fast, private PDF viewer and editor that lives in your browser. Read, mark up and edit locally.

  • Annotate, highlight, merge, split, rotate, watermark
  • Full-text search with match navigation
  • Dark + light themes, 100% local pipeline
Open Studio GitHub

markClipper

v1.1.0

Markdown web clipper and Photo Lab. Save webpages, selections and photo galleries to perfect notes.

  • Six capture modes: article, selection, bookmark, screenshot, gallery, bulk
  • Readability + Turndown pipeline with clean frontmatter
  • Photo Lab up to 250-photo galleries, local library
Open Studio GitHub

Heros Todo

v2.2.0

Markdown, PDF and LaTeX panel studio with 150+ tools for studying, writing and organizing everything.

  • Multi-workspaces across any folders of MD, TXT, TEX, PDF
  • Flashcards, quizzes, Anki export, pomodoro, habits
  • LaTeX math, diagrams, markers, builder studio
Open Studio GitHub

Heros Player

v1.3.0

A full remote for YouTube Music, YouTube, Spotify and any media tab — right from the side panel.

  • Live song readout: title, artist, artwork, progress
  • Seek, volume, shuffle, repeat, likes on every service
  • Probe + act engines with freshness polling
Open Remote GitHub

Heros Markdown

v1.2.0

Free, private, unlimited Markdown studio: perfect rendering, offline KaTeX, every Mermaid diagram.

  • Offline math and all Mermaid diagram types, rendered locally
  • All languages and full RTL support
  • 110 tools: markers, flashcards, quizzes, habits, stopwatch
Open Studio GitHub

Why Heros

Privacy is structural here, not a setting. The suite is built so your data never leaves the machine.

100% local

Every engine — math, diagrams, PDF editing, notebook execution — runs in your browser sandbox. Nothing is uploaded.

Free forever

No subscriptions, no premium tiers, no trials. Every feature, every tool, every release — free with nothing to unlock.

Unlimited

No file caps, no note limits, no daily quotas, no locked exports. Use as much as you want, forever.

No accounts

Nothing to sign up for, nothing to sign in to, nothing to leak. Open the panel and work.

One design language

Panel-first layout, dark and light themes, keyboard-first controls and the same storage model across all six.

Works offline

Disconnect entirely. The suite keeps rendering, editing, executing and exporting without a network.

One Flow, Six Tools

Clip, refine, study, export — the extensions chain together like one product.

markClipper→ Heros Markdown→ Heros Todo→ Heros PDF  ·  Heros NoteBook  ·  Heros Player

Everything stays on your disk. Exports are open formats — .md .pdf .ipynb .zip .json

Install in 30 Seconds

Clone, load unpacked, done. Zips for one-click installs ship in every repository's releases.
